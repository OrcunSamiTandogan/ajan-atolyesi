# Ajan Atölyesi değişiklik günlüğü

## 0.1.0 geliştirme çizgisi

Herkese açık ilk önizlemenin tabanı. Bu dosya tek başına bir GitHub Release veya git etiketi oluşturmaz.

- **Sürüm görünürlüğü:** Hakkında ve `--version` aynı bilgiyi gösterir. Ana hat derleme numarası ayrı hesaplanır; yerel çalışma ve geçmişi olmayan arşivler için numara uydurulmaz.
- **Kurulum akışı:** README’den Pi + NVIDIA, EVREN + DeepSeek veya ikisinin kurulum promptu seçilebiliyor. Sağlayıcılar birbirinden bağımsız.
- **Oturumlar:** Claude Code, Codex, Pi, EVREN DSH CLI, resmî DSH Web ve normal terminal aynı yerel başlatıcıda açılabiliyor.
- **Platform durumu:** Ubuntu doğrulandı; macOS ve Windows WSLg kaynak kurucuları önizleme. [Doğrulama kapsamı](docs/kalite.md).

Bu depo temiz Git geçmişiyle açılır. Yeni kullanıcıya dönük değişiklikleri ilgili sürüm başlığı altına ekleyin.
