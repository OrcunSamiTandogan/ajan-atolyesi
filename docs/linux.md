# Ubuntu 24.04 kurulumu

1. [ZIP'i indir](https://github.com/OrcunSamiTandogan/ajan-atolyesi/archive/refs/heads/master.zip), çıkar ve çıkan klasörde terminal aç.
2. Gerekli paketleri kur:

   ```bash
   sudo apt update
   sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-vte-2.91 tmux
   ```

3. `bash masaustune-kur.sh` çalıştır. Masaüstünden veya uygulama menüsünden **Ajan Atölyesi**'ni aç. Kısayol izin isterse yalnız bu kısayolda **Başlatmaya izin ver**'i seç.
